# DANIEL GROUP — расчёт мебели и КП

Интерактивный опросник, деталировка с ценами и генератор КП для корпусной
мебели на заказ. Один самодостаточный HTML-файл — работает офлайн, без
сервера и без сторонних сервисов.

## Открыть инструмент

- **По ссылке (GitHub Pages):** после включения Pages в настройках репозитория
  сайт будет доступен по адресу вида
  `https://<ваш-github-логин>.github.io/daniel-group-calc-web/`.
- **Локально:** скачайте [`docs/index.html`](docs/index.html) и откройте
  двойным кликом в любом браузере — интернет не нужен.

## Обновление цен

Реальные цены — `source/assets/price_ldsp.csv` (ЛДСП Egger) и
`price_kromka.csv` (кромка). Остальное — `price_list.csv`, плейсхолдер.

После правки CSV пересоберите страницу:

```bash
python source/build_app.py
```

Скрипт подставит новые цены в `docs/index.html` — просто закоммитьте и
запушьте результат, GitHub Pages обновится сам.

## ТВ-табло цеха

[`docs/tablo.html`](docs/tablo.html) — колонки по стадиям сделки, карточки по
дате отгрузки: красная — отгрузка сегодня или просрочена, жёлтая — завтра.
Табло только читает Битрикс24, ничего в нём не меняет.

1. В Битрикс24: «Разработчикам» → «Другое» → «Входящий вебхук», права **CRM**.
   Адрес вебхука — это ключ: никому его не пересылайте.
2. Откройте на ТВ `https://<логин>.github.io/daniel-group-calc-web/tablo.html`,
   нажмите ⚙, вставьте вебхук, «Проверить», выберите воронку и поле с датой
   отгрузки, «Сохранить». Ключ хранится только в браузере этого ТВ.
3. F11 — во весь экран. Табло обновляется раз в минуту; без интернета
   показывает последние данные с пометкой.

Посмотреть без Битрикса: `tablo.html?demo`.

## Цеховой сервер (`shop/`)

Сервер в локальной сети цеха: терминалы участков, справочники (Битрикс, люди
и бейджи, участки и ставки, товары сделки), печать бейджей и титульников с QR,
табло без вебхука на ТВ. Отчёт по сделке — следующий этап.

Нужен только Python 3.10+ (ставить ничего не надо):

```bash
python shop/server.py            # http://<IP-компьютера>:8080/
python shop/server.py --demo     # попробовать на поддельном Битриксе
```

- `/admin` — справочники. Первым делом: вкладка «Битрикс» → вебхук (права
  CRM, im, user), воронка, поле даты отгрузки; затем «Режимы» → PIN.
  Вкладка «Сейчас в цеху» — открытые работы (можно отменить забытую) и
  заказы с пометкой «Проблема».
- `/terminal?section=<id>` — терминал участка (ниже).
- `/tablo` — табло с данными сервера.
- База — `shop/data/shop.db`. Её и надо копировать в бэкап.
- Тесты: `python -m unittest discover -s shop/tests`.

### Терминал участка

На каждом участке — планшет или старый ПК со сканером штрихкодов.

1. **Сканер** переключите в режим клавиатуры (USB HID / Bluetooth HID) с
   Enter после кода — так настроено у большинства сканеров из коробки.
   Раскладку планшета можно не трогать: если сканер «напечатал» `ВП-1234`
   вместо `DG-1234`, сервер поймёт.
2. **Адрес:** откройте на планшете `http://<IP-сервера>:8080/terminal?section=<id>`.
   Готовые ссылки для каждого участка — на главной странице сервера. Планшет
   запомнит участок; сменить — ссылка «сменить участок» внизу экрана.
3. **Бейджи и титульники:** «Справочники → Печать». Бейджи вырежьте и
   заламинируйте, титульник с QR кладите к каждому заказу.

Как отмечаться. На экране всегда одно: «Отсканируйте штрихкод или QR» — бейдж
или титульник, в любом порядке, терминал разберётся сам.

- **Заказ на этапе этого участка** — сразу открывается задание (объёмы участка)
  и «Начал». Вдвоём — пикнуть оба бейджа, деньги делятся поровну. Подошёл второй,
  когда работа уже идёт, — бейдж, заказ, «Присоединиться».
- **Заказ на другом этапе** — экран пишет, где заказ сейчас, и просит бейдж
  начальника производства. Без него «Начал» не пройдёт; кто разрешил, уходит
  комментарием в сделку. Начальника отмечают в «Справочники → Люди» галочкой
  «Начальник» и печатают ему бейдж.
- **Закончил:** пикнуть заказ → «Готово», «Готово с замечанием» (выбрать
  причину) или «Проблема» (причина, мастеру уходит уведомление в Битрикс).
  После «Готово» на экране — сколько заработано за заказ, сегодня и за месяц,
  а сделка сама уходит на следующий участок.
- **ОТК:** у заказа есть ещё кнопка «Брак» — выбрать участок, причину и чья
  вина. Заказ вернётся на участок с пометкой «переделка».

Очередь участка по дате отгрузки — кнопка «Очередь участка» внизу экрана
(красные — отгрузка сегодня или просрочена, жёлтые — завтра). Без интернета
терминалы работают — отметки уйдут в Битрикс, когда связь вернётся.

### Камера вместо сканера

Если на планшете нет сканера — внизу экрана «📷 Камера» (планшет запомнит).
Включается фронтальная камера: бейдж или титульник подносят QR к экрану.
⟲ на превью — задняя камера. Один и тот же код срабатывает снова, только если
его убрать из кадра, поэтому титульник можно держать, пока жмёте кнопки.

Браузер даёт камеру только на защищённом адресе. Два способа:

1. **Android + Chrome** (проще, один раз на каждом планшете): открыть
   `chrome://flags/#unsafely-treat-insecure-origin-as-secure`, вписать адрес
   сервера, например `http://192.168.1.10:8080`, выбрать **Enabled** и нажать
   **Relaunch**. Потом открыть терминал, «📷 Камера», разрешить камеру.
2. **https на сервере** (любые планшеты, в том числе iPad): один раз сделать
   сертификат и запускать сервер с ним:

   ```bash
   openssl req -x509 -newkey rsa:2048 -nodes -days 3650 -subj "/CN=daniel-shop" \
     -keyout shop/data/key.pem -out shop/data/cert.pem
   python shop/server.py --cert shop/data/cert.pem --key shop/data/key.pem
   ```

   Адреса станут `https://<IP>:8080/…`. Сертификат свой, поэтому при первом
   открытии браузер предупредит — «Дополнительно» → «Перейти на сайт».
   На Windows `openssl` есть в Git for Windows: `C:\Program Files\Git\usr\bin\openssl.exe`.

QR читается в любом браузере, штрихкод камерой — только в Chrome на Android.
На бейджах и титульниках печатаются оба.

**Демо для телефона** — [`docs/terminal-demo.html`](docs/terminal-demo.html), на GitHub Pages:
`https://<логин>.github.io/daniel-group-calc-web/terminal-demo.html#kromka` (после `#` —
участок: `raspil`, `kromka`, `prisadka`, `upakovka`, `otk`). Терминал без сервера и
Битрикса на примерных данных, с камерой и «тест-сканером». Собирается из настоящего
терминала: после правок `shop/web/terminal.html` — `python shop/phone-demo/build.py`.

Пилот начните с **присадки**: один участок, один планшет, пара бейджей. Когда
там приживётся — остальные участки, потом месяц теневого режима («Режимы»).
